01

Open two versions

Paste code or open a file on each side. Put your reference in A and the version you want to change in B.

02

Review each difference

Jump to highlighted lines. Choose Use A to replace a block or Keep B to mark it reviewed. Edit either side; Undo and Redo are available.

03

Download your result

Click Download B to save a copy. Save before closing or reloading the tab: your session is not stored.

Keep it close

Open Chrome’s Extensions menu and pin Code Compare Local. Click its icon whenever you want to compare code.

Made for code and text

Use UTF-8 text files, not PDF or Word documents. Supported syntax checks run locally; code is never executed. The editor and this guide are in English.
