## Основа и границы данных

Использована уже проведённая выгрузка Semrush от **17 октября 2026**:
`code-compare-semrush-us-europe-2026-10-17.md`. Новый запрос к Semrush для этого
комплекта не выполнялся. В исходном `phrase_all` для `compare code` указана
база **202609**; у остальных bulk-отчётов отдельная дата снимка не возвращалась.

Volume — оценка среднемесячного веб-поиска за 12 месяцев, не поиск внутри
Chrome Web Store, не уникальные люди и не готовность платить. Близкие запросы
не складываются в аудиторию. Английская база карточки рассчитана на США;
локализованные тексты не означают, что спрос во всех странах одинаков.

## Применение рекомендаций буткемпа

- Краткое описание: **106 символов**, в пределах 132. Содержит естественные
  формулировки `compare code`, `side by side`, `code diff tool`, `check syntax`,
  `save files offline`.
- Полное описание: **4,472 символа**, 14 заголовков/тематических блоков; смысловые
  части посвящены конкретным действиям и ограничениям продукта.
- Идентичность продукта сохранена. Предложение «Code Diff Checker — Compare &
  Edit Code» из раннего исследования не стало новым названием.
- Набор из примерно 30 ключей рассматривается как семантический ориентир, не
  обязательная квота вхождений. Формулировка может остаться с нулём вхождений,
  если добавление ухудшает текст или создаёт ложное обещание.
- Нет списка ключей в публичном описании, навязанных повторов, сравнительных
  превосходных заявлений или слов `best`, `recommended`, `premium`, `free`, `#1`.
- Ключевые слова не используются для обещания PDF/Word, сравнения репозиториев,
  Git merge, форматирования, выполнения кода или полноценного аудита безопасности.

## Темы, которые раскрывает описание

Это смысловые формулировки, а не новые измеренные поисковые запросы:

1. Сравнение двух версий кода.
2. Code diff рядом в двух редакторах.
3. Подсветка добавлений, удалений и замен.
4. Список изменённых строк и переход по номерам.
5. Перенос отдельного блока A → B.
6. Решение Keep B и прогресс просмотра.
7. Прямое редактирование обеих версий.
8. Undo/Redo для правок и переносов.
9. Одинаковые блоки для одинаковых итоговых текстов.
10. Отображение отступов, пробелов и табуляции.
11. Сворачивание неизменённых фрагментов.
12. Локальные синтаксические проверки.
13. Сравнение JavaScript, Python, JSON и YAML как текста.
14. Сохранение нового UTF-8 файла.
15. Сохранение исходных переносов строк и BOM.
16. Работа без аккаунта, облачной обработки и LLM.
17. Локальная welcome page и встроенный пример.
18. Явные ограничения форматов, объёма и восстановления сессии.

## Официальные рамки карточки

https://developer.chrome.com/docs/webstore/program-policies/listing-requirements

В описании должны быть ясны реальные функции. Не заполняем текст повторяющимися
или нерелевантными ключами ради количества. Окончательную карточку и её переводы
нужно вносить через соответствующие языковые поля Chrome Web Store; содержимое
`_locales` автоматически не переводит интерфейс редактора.
