ЭТО РАСШИРЕНИЕ ПРЕДНАЗНАЧЕНО ДЛЯ БЕТА-ТЕСТИРОВАНИЯ.

Сравните две версии кода, проверьте различия и сохраните нужный результат. Code Compare Local — инструмент сравнения кода, который работает в браузере без интернета. Откройте исходную версию в A, изменённую — в B и просмотрите подсвеченные изменения рядом.

НАЧНИТЕ С ПРИМЕРА
После первой установки открывается приветственная страница. Перейдите в редактор или попробуйте встроенный пример JavaScript без подготовки файлов. Редактор и приветственная страница работают на английском. Перевод описания магазина и названия расширения не меняет язык интерфейса.

НАЙДИТЕ ИЗМЕНЁННЫЕ СТРОКИ
Представление различий показывает добавления, удаления и замены. В списке Differences указаны номера строк A/B и фрагмент каждого изменённого блока. Выберите пункт или нажмите Previous и Next, чтобы перейти к нему, даже если изменения расположены далеко друг от друга в длинном файле.

ВЫБЕРИТЕ, ЧТО ОСТАВИТЬ В B
Нажмите Use A, чтобы скопировать выбранный блок в B, или Keep B, чтобы отметить различие как просмотренное без изменения текста. Use A → B обрабатывает одно различие за раз; All A → B заменяет весь результат. Индикатор просмотра помогает отслеживать решения, принятые в текущем сеансе.

РЕДАКТИРУЙТЕ И ОТМЕНЯЙТЕ
Редактируйте код прямо в любом из двух окон. Кнопки Undo и Redo над редакторами относятся к B; Ctrl/Cmd+Z действует в активном редакторе. Переносы блоков тоже можно отменять. Keep B — отметка просмотра, а не изменение текста. Ручное редактирование сбрасывает прогресс просмотра, чтобы прежние решения незаметно не переносились на изменившийся текст.

ПОЛУЧАЙТЕ СТАБИЛЬНЫЕ РАЗЛИЧИЯ
Одинаковые итоговые тексты A/B дают одинаковые блоки различий: после прямой загрузки, редактирования, отмены или повтора изменений. Это упрощает повторное сравнение кода после сохранения. Сложные различия могут объединяться в более крупные блоки; блок не всегда является наименьшим возможным изменением.

СДЕЛАЙТЕ КОД УДОБНЕЕ ДЛЯ ЧТЕНИЯ
Выберите размер текста от 14 до 20 px и включите или отключите перенос длинных строк. Only changes сворачивает длинные неизменённые участки, оставляя по три строки контекста вокруг различий. Разверните участок, когда потребуется больше контекста. Show spaces & tabs показывает отступы, не меняя код.

ПРОВЕРЯЙТЕ ПОДДЕРЖИВАЕМЫЙ СИНТАКСИС
Проверка синтаксиса выполняется локально после загрузки, вставки, редактирования и переноса кода. Нажмите Check syntax, чтобы запустить её повторно, затем выберите указанное место для перехода к проблеме. Синтаксические проверки доступны для JavaScript, JSX, TypeScript, TSX, JSON и YAML. Для Python предусмотрена предварительная проверка грамматики и отступов.

УЧИТЫВАЙТЕ ГРАНИЦЫ ПРОВЕРКИ
Расширение не запускает код и не исправляет его автоматически. Каждая сторона проверяется как самостоятельный файл, поэтому незавершённый фрагмент может давать ошибки. Проверка типов TypeScript и валидация схем YAML не входят в возможности. Проверки Python не заменяют проверку самим Python. Для остальных языков из списка доступна только подсветка; корректный синтаксис не доказывает правильность работы программы.

СОХРАНЯЙТЕ ИЗМЕНЁННЫЙ ФАЙЛ
Download B создаёт новый файл UTF-8, не перезаписывая оригинал. При скачивании сохраняются пробелы, табуляция, маркер порядка байтов UTF-8 и исходные окончания строк в неизменённом тексте. Перенесённые блоки сохраняют окончания строк из A. Новые введённые строки используют основной формат окончаний строк редактируемого файла. Copy B копирует в буфер обмена, который может нормализовать окончания строк.

ПРИМЕНЯЙТЕ ДЛЯ ПОВСЕДНЕВНОЙ ПРОВЕРКИ КОДА
Сравните код JavaScript перед переносом обновления в свой проект. Проверьте файл Python, если при переносе могли измениться отступы. Сравните файлы конфигурации JSON или YAML и просмотрите изменённые значения как текст. Сравнение JSON текстовое: оно не сопоставляет объекты по смыслу и не игнорирует порядок ключей. Это проверка двух файлов, а не всего репозитория.

ОБРАБАТЫВАЙТЕ НА СВОЁМ УСТРОЙСТВЕ
Не нужны аккаунт, API-ключ, внешний AI-сервис, аналитика или загрузка кода на сервер. Расширение работает в собственной вкладке редактора и не читает другие вкладки или переписки. Вставляйте или открывайте код самостоятельно, в том числе фрагменты из чата. Автоматического подключения к ChatGPT, Claude или Gemini нет.

СОХРАНЯЙТЕ ПЕРЕД ЗАКРЫТИЕМ
Текст, история отмены и состояние просмотра остаются в памяти на время сеанса. Закрытие или перезагрузка редактора не восстанавливают вашу работу. Скачайте результат перед выходом из вкладки. Облачной истории и фонового резервного копирования нет.

ОГРАНИЧЕНИЯ ФАЙЛОВ В БЕТЕ
Открывайте текстовые файлы UTF-8 размером до 512 KiB, длиной до 200 000 кодовых единиц UTF-16 и до 4 000 строк с каждой стороны. PDF, документы Word, двоичные файлы и целые папки не поддерживаются. Начните с двух знакомых файлов кода: найдите различие, внесите исправление, попробуйте Undo и скачайте B.
