この拡張機能はベータテスト用です。

2つのコードのバージョンを比較し、差分を確認して、必要な結果を保存できます。Code Compare Local はブラウザ内でオフライン動作するコード比較ツールです。基準のバージョンを A、修正したバージョンを B に開き、横に並べてハイライトされた変更を確認します。

サンプルから始める
初回インストール後にウェルカムページが開きます。エディタを開くか、ファイルを準備せずに内蔵の JavaScript サンプルを試せます。エディタとウェルカムページの表示言語は英語です。ストアの説明文や拡張機能名が翻訳されていても、画面の言語は変わりません。

変更された行を見つける
差分表示で追加、削除、置換を確認できます。Differences 一覧には A/B の行番号と各変更ブロックのプレビューが表示されます。項目を選ぶか Previous と Next で移動できます。長いファイル内で離れた場所にある変更にも移動できます。

B に残す内容を選ぶ
Use A をクリックすると選択したブロックを B にコピーします。Keep B は内容を変えずに、その差分を確認済みとして記録します。Use A → B は1つの差分に適用され、All A → B は結果全体を置き換えます。確認の進捗表示で、現在のセッション中に行った判断を追跡できます。

編集と取り消し
どちらのペインでもコードを直接編集できます。エディタ上部の Undo と Redo は B に作用し、Ctrl/Cmd+Z はフォーカスのあるエディタに作用します。ブロックの転送も取り消せます。Keep B は確認済みの印であり、テキストの編集ではありません。手動で編集すると確認の進捗がリセットされ、変更後のテキストに過去の判断が黙って引き継がれることを防ぎます。

一貫した差分表示
A/B の最終的なテキストが同じなら、ファイルの直接読み込み、編集、取り消し、やり直しのどの操作を経ても、同じ差分ブロックになります。保存後にコードを再比較しやすくなります。複雑な差分は大きめのブロックにまとめられる場合があり、常に最小単位の変更を示すわけではありません。

コードを読みやすくする
コードの文字サイズを14～20 pxから選び、行の折り返しを切り替えられます。Only changes は変更のない長い区間を折りたたみ、差分の前後に3行の文脈を残します。必要に応じて折りたたんだ区間を展開できます。Show spaces & tabs はコードを変えずにインデントを見えるようにします。

対応する構文をチェック
コードの読み込み、貼り付け、編集、転送の後に、構文チェックがローカルで実行されます。Check syntax で再実行し、報告された位置を選ぶと問題の箇所に移動できます。JavaScript、JSX、TypeScript、TSX、JSON、YAML に対応しています。Python には文法とインデントの簡易チェックがあります。

チェックの範囲を理解する
コードの実行や自動修正は行いません。それぞれのペインを独立したファイルとして検査するため、未完成のコード片ではエラーが出ることがあります。TypeScript の型チェックや YAML スキーマの検証は含まれません。Python のチェックは Python 自体による検証の代わりにはなりません。その他の選択可能な言語は色分け表示のみです。構文が正しくても、動作が正しいとは限りません。

修正したファイルを保存
Download B は元のファイルを上書きせず、新しい UTF-8 ファイルを作成します。ダウンロード時にはスペース、タブ、UTF-8 のバイトオーダーマーク、および変更していないテキストの元の改行コードを保持します。転送したブロックには A の改行コードが保持されます。新しく入力した行には編集対象のファイルで主に使われている改行形式が適用されます。Copy B はクリップボードへのコピー用です。クリップボードでは改行コードが統一される場合があります。

日常のコードレビューに
JavaScript コードの更新をプロジェクトにコピーする前に比較できます。転送時にインデントが変わった可能性がある Python ファイルを確認できます。JSON や YAML の設定ファイルを比較し、値の変更をテキストとして確認できます。JSON の比較は文字列として行い、オブジェクトの意味による対応付けやキーの順序の無視はしません。2つのファイルを確認するツールであり、リポジトリ全体をレビューするものではありません。

処理は端末内で完結
アカウント、API キー、外部 AI サービス、アクセス解析、コードのアップロードは必要ありません。拡張機能は専用のエディタタブで動作し、他のタブや会話を読み取りません。チャットのコード片を含め、利用者自身がコードを貼り付けるか開きます。ChatGPT、Claude、Gemini への自動接続は行いません。

閉じる前に保存
テキスト、取り消し履歴、確認状態はセッション中のメモリ内に保持されます。エディタを閉じたり再読み込みしたりしても作業は復元されません。タブを離れる前に結果をダウンロードしてください。クラウド履歴やバックグラウンドのバックアップはありません。

ベータ版のファイル制限
各ペインで開ける UTF-8 テキストファイルは最大512 KiB、200,000 UTF-16コード単位、4,000行です。PDF、Word文書、バイナリファイル、フォルダ全体には対応していません。内容を知っている2つのコードファイルで、差分を見つけ、修正し、Undo を試してから B をダウンロードしてください。
