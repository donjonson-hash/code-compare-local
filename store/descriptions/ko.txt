이 확장 프로그램은 베타 테스트용입니다.

두 버전의 코드를 비교하고 차이점을 검토한 뒤 원하는 결과를 저장하세요. Code Compare Local은 브라우저 안에서 오프라인으로 작동하는 코드 비교 도구입니다. 기준 버전을 A에, 수정한 버전을 B에 열고 나란히 표시된 변경 사항을 확인할 수 있습니다.

예제로 시작하기
처음 설치하면 시작 안내 페이지가 열립니다. 편집기를 열거나 파일을 준비하지 않고 내장 JavaScript 예제를 사용해 볼 수 있습니다. 편집기와 시작 안내 페이지는 영어로 표시됩니다. 번역된 스토어 설명과 확장 프로그램 이름은 인터페이스 언어를 바꾸지 않습니다.

변경된 줄 찾기
코드 차이 보기에서 추가, 삭제, 교체 내용을 확인하세요. Differences 목록에는 A/B 줄 번호와 변경된 각 블록의 미리보기가 표시됩니다. 항목을 선택하거나 Previous와 Next를 사용해 해당 위치로 이동할 수 있습니다. 긴 파일에서 서로 멀리 떨어진 변경 사항에도 이동할 수 있습니다.

B에 넣을 내용 선택하기
Use A를 클릭하면 선택한 블록을 B로 복사합니다. Keep B는 내용을 바꾸지 않고 해당 차이점을 검토한 것으로 표시합니다. Use A → B는 한 번에 하나의 차이점에 적용되며, All A → B는 결과 전체를 교체합니다. 검토 진행률을 통해 현재 세션에서 내린 결정을 확인할 수 있습니다.

편집과 실행 취소
어느 쪽 창에서든 코드를 직접 편집할 수 있습니다. 편집기 위의 Undo와 Redo는 B에 적용되고, Ctrl/Cmd+Z는 포커스가 있는 편집기에 적용됩니다. 블록 전송도 실행 취소할 수 있습니다. Keep B는 검토 표시이며 텍스트 편집이 아닙니다. 수동으로 편집하면 검토 진행률이 초기화되어, 이전 결정이 바뀐 텍스트에 그대로 이어지는 것을 막습니다.

일관된 차이점 확인하기
최종 A/B 텍스트가 같으면 파일을 직접 불러오거나, 편집하거나, 실행 취소와 다시 실행을 거쳐도 같은 차이 블록이 표시됩니다. 따라서 저장한 뒤 코드를 다시 비교하기 쉽습니다. 복잡한 차이점은 더 큰 블록으로 묶일 수 있으며, 블록이 항상 가능한 가장 작은 변경 단위를 뜻하지는 않습니다.

코드를 더 읽기 쉽게 표시하기
코드 글자 크기를 14~20 px에서 선택하고 줄 바꿈 표시를 켜거나 끌 수 있습니다. Only changes는 변경되지 않은 긴 구간을 접고 차이점 주변에 문맥을 위한 세 줄을 남깁니다. 더 많은 문맥이 필요하면 접힌 구간을 펼치세요. Show spaces & tabs는 코드를 바꾸지 않고 들여쓰기를 보이게 합니다.

지원되는 구문 검사하기
코드를 불러오기, 붙여넣기, 편집 또는 전송한 뒤 구문 검사가 기기 내에서 실행됩니다. Check syntax를 눌러 다시 검사한 다음, 보고된 위치를 선택해 문제 지점으로 이동하세요. JavaScript, JSX, TypeScript, TSX, JSON, YAML 구문 검사를 지원합니다. Python은 기본적인 문법과 들여쓰기 검사를 제공합니다.

검사의 의미 이해하기
확장 프로그램은 코드를 실행하거나 자동으로 수정하지 않습니다. 양쪽을 각각 독립된 파일로 검사하므로 미완성 코드 조각에서는 오류가 보고될 수 있습니다. TypeScript 타입 검사와 YAML 스키마 검증은 포함되지 않습니다. Python 검사는 Python 자체를 사용한 검증을 대체하지 않습니다. 목록의 다른 언어는 구문 강조만 제공합니다. 올바른 구문이 올바른 동작을 보장하지는 않습니다.

수정한 파일 저장하기
Download B는 원본을 덮어쓰지 않고 새 UTF-8 파일을 만듭니다. 다운로드는 공백, 탭, UTF-8 바이트 순서 표시와 변경되지 않은 텍스트의 원래 줄바꿈 형식을 유지합니다. 전송한 블록은 A의 줄바꿈 형식을 유지합니다. 새로 입력한 줄에는 편집 중인 파일에서 주로 쓰는 줄바꿈 형식이 적용됩니다. Copy B로 클립보드에 복사할 수 있으며, 클립보드에서는 줄바꿈 형식이 통일될 수 있습니다.

일상적인 코드 검토에 활용하기
업데이트를 프로젝트에 복사하기 전에 JavaScript 코드를 비교하세요. 전송 중 들여쓰기가 달라졌을 수 있는 Python 파일을 확인하세요. JSON이나 YAML 설정 파일을 비교하고 변경된 값을 텍스트로 검토하세요. JSON 비교는 텍스트 비교이며, 의미를 기준으로 객체를 대응시키거나 키 순서를 무시하지 않습니다. 이 도구는 두 파일을 검사하며 저장소 전체를 검토하지 않습니다.

처리는 기기 안에서
계정, API 키, 외부 AI 서비스, 분석 추적 또는 코드 업로드가 필요하지 않습니다. 확장 프로그램은 자체 편집기 탭에서 작동하고 다른 탭이나 대화를 읽지 않습니다. 채팅에서 가져온 코드 조각을 포함해 사용자가 직접 코드를 붙여넣거나 엽니다. ChatGPT, Claude, Gemini에 자동으로 연결하지 않습니다.

닫기 전에 저장하기
텍스트, 실행 취소 기록, 검토 상태는 세션 동안 메모리에만 남습니다. 편집기를 닫거나 새로고침하면 작업이 복원되지 않습니다. 탭을 떠나기 전에 결과를 다운로드하세요. 클라우드 기록이나 백그라운드 백업은 없습니다.

베타 버전 파일 제한
각 창에서 최대 512 KiB, 200,000 UTF-16 코드 단위, 4,000줄의 UTF-8 텍스트 파일을 열 수 있습니다. PDF, Word 문서, 바이너리 파일, 폴더 전체는 지원하지 않습니다. 잘 알고 있는 코드 파일 두 개로 시작해 차이점을 찾고, 수정하고, Undo를 사용해 본 다음 B를 다운로드하세요.
