هذا الامتداد مخصص لاختبار النسخة التجريبية.

قارن نسختين من الشفرة، وراجع الفروق بينهما، واحفظ النتيجة التي تريدها. Code Compare Local أداة لمقارنة الشفرة تعمل داخل متصفحك دون اتصال بالإنترنت. افتح النسخة المرجعية في A والنسخة المعدلة في B، ثم راجع التغييرات المظللة جنبًا إلى جنب.

ابدأ بمثال
تفتح صفحة الترحيب بعد التثبيت الأول. افتح المحرر أو جرّب مثال JavaScript المضمّن دون تجهيز ملفات. المحرر وصفحة الترحيب باللغة الإنجليزية. ترجمة وصف المتجر واسم الامتداد لا تغيّر لغة الواجهة.

اعثر على الأسطر المعدلة
تعرض مقارنة الشفرة الإضافات والحذف والاستبدال. تعرض قائمة Differences أرقام الأسطر في A وB ومعاينة لكل كتلة معدلة. اختر عنصرًا أو استخدم Previous وNext للانتقال إليه، بما في ذلك التغييرات المتباعدة في الملفات الطويلة.

اختر ما تريد الاحتفاظ به في B
انقر Use A لنسخ الكتلة المحددة إلى B، أو Keep B لتسجيل مراجعة الفرق دون تغيير النص. يعمل Use A → B على فرق واحد في كل مرة؛ أما All A → B فيستبدل النتيجة كاملة. يساعدك مؤشر تقدم المراجعة على متابعة قراراتك خلال الجلسة الحالية.

عدّل وتراجع
عدّل الشفرة مباشرة في أي من اللوحتين. يطبّق زرا Undo وRedo فوق المحررين على B، بينما يعمل Ctrl/Cmd+Z في المحرر الذي عليه التركيز. يمكنك التراجع عن نقل الكتل أيضًا. Keep B علامة مراجعة وليست تعديلًا للنص. تعيد التعديلات اليدوية تقدم المراجعة إلى البداية حتى لا تُنقل القرارات السابقة إلى نص تغير دون تنبيه.

احصل على فروق متسقة
ينتج النص النهائي نفسه في A وB كتل الفروق نفسها، سواء حمّلت الملفات مباشرة أو عدّلتها أو تراجعت عن التغييرات وأعدتها. يسهل ذلك مقارنة الشفرة مرة أخرى بعد الحفظ. قد تُجمع الفروق المعقدة في كتل أوسع؛ فالكتلة ليست دائمًا أصغر تغيير ممكن.

اجعل الشفرة أسهل قراءة
اختر حجمًا للشفرة من 14 إلى 20 بكسل، وفعّل التفاف الأسطر أو عطّله. يطوي Only changes المقاطع الطويلة غير المعدلة، مع إبقاء ثلاثة أسطر للسياق حول الفروق. يمكنك توسيع أي مقطع مطوي عند الحاجة إلى سياق إضافي. يُظهر Show spaces & tabs المسافات وعلامات الجدولة لتوضيح الإزاحة دون تغيير الشفرة.

افحص الصياغة المدعومة
تُجرى فحوص الصياغة محليًا بعد تحميل الشفرة أو لصقها أو تعديلها أو نقلها. انقر Check syntax لإعادة الفحص، ثم اختر موضعًا مذكورًا للانتقال إلى المشكلة. تتوفر فحوص الصياغة لـ JavaScript وJSX وTypeScript وTSX وJSON وYAML. تتوفر لـ Python فحوص أولية للقواعد والإزاحة.

اعرف حدود الفحص
لا ينفذ الامتداد الشفرة ولا يصلحها تلقائيًا. يُفحص كل جانب باعتباره ملفًا مستقلًا، لذا قد تظهر أخطاء في مقتطف غير مكتمل. لا يتضمن فحص أنواع TypeScript أو التحقق من مخطط YAML. لا تغني فحوص Python عن التحقق باستخدام Python نفسه. تقدم اللغات الأخرى المدرجة تلوين الصياغة فقط؛ وصحة الصياغة لا تثبت صحة سلوك البرنامج.

احفظ الملف المعدل
ينشئ Download B ملف UTF-8 جديدًا دون الكتابة فوق الأصل. يحافظ التنزيل على المسافات وعلامات الجدولة وعلامة ترتيب البايتات UTF-8 ونهايات الأسطر الأصلية في النص غير المعدل. تحتفظ الكتل المنقولة بنهايات الأسطر من A. تستخدم الأسطر المكتوبة حديثًا نمط نهاية الأسطر الغالب في الملف المعدل. استخدم Copy B للنسخ إلى الحافظة؛ وقد توحّد الحافظة نهايات الأسطر.

استخدمه في مراجعة الشفرة اليومية
قارن شفرة JavaScript قبل نسخ تحديث إلى مشروعك. راجع ملف Python عندما يحتمل أن تكون الإزاحة قد تغيرت أثناء النقل. قارن ملفات إعداد JSON أو YAML وافحص القيم المعدلة كنص. مقارنة JSON نصية: لا تطابق الكائنات بحسب المعنى ولا تتجاهل ترتيب المفاتيح. هذه فحوص لملفين، وليست مراجعة لمستودع كامل.

أبقِ المعالجة على جهازك
لا تحتاج إلى حساب أو مفتاح API أو خدمة ذكاء اصطناعي خارجية أو تحليلات أو رفع الشفرة. يعمل الامتداد داخل علامة تبويب المحرر الخاصة به، ولا يقرأ علامات التبويب الأخرى أو المحادثات. الصق الشفرة أو افتحها بنفسك، بما فيها مقتطفات المحادثات. لا يتصل تلقائيًا بـ ChatGPT أو Claude أو Gemini.

احفظ قبل الإغلاق
يبقى النص وسجل التراجع وحالة المراجعة في الذاكرة أثناء الجلسة. لا يؤدي إغلاق المحرر أو إعادة تحميله إلى استعادة عملك. نزّل النتيجة قبل مغادرة علامة التبويب. لا يوجد سجل سحابي أو نسخ احتياطي في الخلفية.

حدود ملفات النسخة التجريبية
افتح ملفات نصية بترميز UTF-8 بحد أقصى 512 KiB و200,000 وحدة شفرة UTF-16 و4,000 سطر لكل جانب. ملفات PDF ومستندات Word والملفات الثنائية والمجلدات الكاملة غير مدعومة. ابدأ بملفي شفرة تعرفهما: اعثر على فرق، وأجرِ تصحيحًا، وجرّب Undo، ثم نزّل B.
