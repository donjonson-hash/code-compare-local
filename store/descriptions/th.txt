ส่วนขยายนี้มีไว้สำหรับการทดสอบรุ่นเบตา

เปรียบเทียบโค้ดสองเวอร์ชัน ตรวจดูความแตกต่าง แล้วบันทึกผลลัพธ์ที่ต้องการ Code Compare Local เป็นเครื่องมือเปรียบเทียบโค้ดที่ทำงานแบบออฟไลน์ในเบราว์เซอร์ เปิดเวอร์ชันอ้างอิงใน A และเวอร์ชันที่แก้ไขใน B แล้วตรวจดูการเปลี่ยนแปลงที่ไฮไลต์ไว้แบบวางเทียบกัน

เริ่มต้นด้วยตัวอย่าง
หน้าต้อนรับจะเปิดหลังจากติดตั้งครั้งแรก เปิดตัวแก้ไขหรือทดลองตัวอย่าง JavaScript ที่มีให้โดยไม่ต้องเตรียมไฟล์ ตัวแก้ไขและหน้าต้อนรับเป็นภาษาอังกฤษ การแปลคำอธิบายในร้านค้าและชื่อส่วนขยายไม่ได้เปลี่ยนภาษาของอินเทอร์เฟซ

ค้นหาบรรทัดที่เปลี่ยนไป
มุมมองเปรียบเทียบโค้ดแสดงส่วนที่เพิ่ม ลบ และแทนที่ รายการ Differences แสดงหมายเลขบรรทัด A/B และตัวอย่างแต่ละบล็อกที่เปลี่ยนไป เลือกรายการหรือใช้ Previous และ Next เพื่อไปยังตำแหน่งนั้น รวมถึงการเปลี่ยนแปลงที่อยู่ห่างกันในไฟล์ขนาดยาว

เลือกสิ่งที่จะเก็บไว้ใน B
คลิก Use A เพื่อคัดลอกบล็อกที่เลือกไปยัง B หรือ Keep B เพื่อทำเครื่องหมายว่าตรวจแล้วโดยไม่เปลี่ยนข้อความ Use A → B จัดการความแตกต่างทีละรายการ ส่วน All A → B จะแทนที่ผลลัพธ์ทั้งหมด ความคืบหน้าการตรวจช่วยติดตามการตัดสินใจในเซสชันปัจจุบัน

แก้ไขและเลิกทำ
แก้ไขโค้ดได้โดยตรงในช่องใดก็ได้ ปุ่ม Undo และ Redo เหนือตัวแก้ไขใช้กับ B ส่วน Ctrl/Cmd+Z ใช้กับตัวแก้ไขที่กำลังโฟกัสอยู่ การย้ายบล็อกก็เลิกทำได้เช่นกัน Keep B เป็นเครื่องหมายการตรวจ ไม่ใช่การแก้ไขข้อความ เมื่อแก้ไขด้วยตนเอง ความคืบหน้าการตรวจจะเริ่มใหม่ เพื่อไม่ให้นำการตัดสินใจเดิมไปใช้กับข้อความที่เปลี่ยนไปโดยไม่แจ้งให้ทราบ

ได้ความแตกต่างที่สม่ำเสมอ
ข้อความสุดท้ายใน A/B ที่เหมือนกันจะให้บล็อกความแตกต่างเหมือนกัน ไม่ว่าจะโหลดไฟล์โดยตรง แก้ไข หรือเลิกทำและทำซ้ำ จึงช่วยให้เปรียบเทียบโค้ดอีกครั้งหลังบันทึกได้ง่ายขึ้น ความแตกต่างที่ซับซ้อนอาจรวมเป็นบล็อกที่ใหญ่ขึ้น บล็อกหนึ่งจึงไม่ได้เป็นการเปลี่ยนแปลงที่เล็กที่สุดเสมอไป

ทำให้โค้ดอ่านง่ายขึ้น
เลือกขนาดโค้ดตั้งแต่ 14 ถึง 20 px และเปิดหรือปิดการตัดบรรทัดตามความกว้างของช่อง Only changes ยุบส่วนยาวที่ไม่เปลี่ยนแปลง โดยแสดงบริบทสามบรรทัดรอบความแตกต่าง ขยายส่วนที่ยุบไว้ได้เมื่อต้องการบริบทเพิ่มเติม Show spaces & tabs ทำให้เห็นการเยื้องโดยไม่แก้ไขโค้ด

ตรวจไวยากรณ์ที่รองรับ
การตรวจไวยากรณ์ทำงานบนเครื่องหลังโหลด วาง แก้ไข และย้ายโค้ด คลิก Check syntax เพื่อตรวจอีกครั้ง แล้วเลือกตำแหน่งที่รายงานเพื่อไปยังจุดที่มีปัญหา มีการตรวจไวยากรณ์สำหรับ JavaScript, JSX, TypeScript, TSX, JSON และ YAML ส่วน Python มีการตรวจไวยากรณ์และการเยื้องเบื้องต้น

เข้าใจความหมายของการตรวจ
ส่วนขยายไม่ได้รันโค้ดหรือแก้ไขโดยอัตโนมัติ แต่ละฝั่งถูกตรวจเป็นไฟล์เดี่ยว จึงอาจรายงานข้อผิดพลาดเมื่อโค้ดยังไม่ครบ ไม่รวมการตรวจชนิดข้อมูล TypeScript หรือการตรวจสอบสคีมา YAML การตรวจ Python ใช้แทนการตรวจด้วย Python เองไม่ได้ ภาษาอื่นในรายการมีเพียงการเน้นสีไวยากรณ์ ไวยากรณ์ที่ถูกต้องไม่ได้ยืนยันว่าโปรแกรมทำงานถูกต้อง

บันทึกไฟล์ที่แก้ไขแล้ว
Download B สร้างไฟล์ UTF-8 ใหม่โดยไม่เขียนทับต้นฉบับ ไฟล์ที่ดาวน์โหลดจะคงช่องว่าง แท็บ เครื่องหมายลำดับไบต์ UTF-8 และรูปแบบขึ้นบรรทัดใหม่เดิมในข้อความส่วนที่ไม่เปลี่ยนแปลง บล็อกที่ย้ายมาจะคงรูปแบบขึ้นบรรทัดใหม่จาก A บรรทัดที่พิมพ์ใหม่ใช้รูปแบบขึ้นบรรทัดใหม่หลักของไฟล์ที่กำลังแก้ไข ใช้ Copy B เพื่อคัดลอกลงคลิปบอร์ด ซึ่งอาจปรับรูปแบบขึ้นบรรทัดใหม่ให้เหมือนกัน

ใช้ตรวจโค้ดในงานประจำวัน
เปรียบเทียบโค้ด JavaScript ก่อนคัดลอกการอัปเดตลงในโปรเจกต์ ตรวจไฟล์ Python เมื่อการเยื้องอาจเปลี่ยนไประหว่างย้ายโค้ด เปรียบเทียบไฟล์ตั้งค่า JSON หรือ YAML และตรวจค่าที่เปลี่ยนไปในรูปข้อความ การเปรียบเทียบ JSON เป็นการเปรียบเทียบข้อความ ไม่จับคู่ออบเจ็กต์ตามความหมายหรือมองข้ามลำดับคีย์ เครื่องมือนี้ตรวจสองไฟล์ ไม่ใช่ตรวจรีโพซิทอรีทั้งหมด

ประมวลผลบนอุปกรณ์ของคุณ
ไม่ต้องใช้บัญชี คีย์ API บริการ AI ภายนอก การวิเคราะห์ติดตาม หรือการอัปโหลดโค้ด ส่วนขยายทำงานในแท็บตัวแก้ไขของตนเองและไม่อ่านแท็บหรือบทสนทนาอื่น คุณต้องวางหรือเปิดโค้ดเอง รวมถึงโค้ดจากแชต ส่วนขยายไม่เชื่อมต่อกับ ChatGPT, Claude หรือ Gemini โดยอัตโนมัติ

บันทึกก่อนปิด
ข้อความ ประวัติการเลิกทำ และสถานะการตรวจอยู่ในหน่วยความจำระหว่างเซสชัน การปิดหรือโหลดตัวแก้ไขใหม่จะไม่กู้คืนงานของคุณ ดาวน์โหลดผลลัพธ์ก่อนออกจากแท็บ ไม่มีประวัติบนคลาวด์หรือการสำรองข้อมูลเบื้องหลัง

ข้อจำกัดไฟล์ของรุ่นเบตา
เปิดไฟล์ข้อความ UTF-8 ได้สูงสุดฝั่งละ 512 KiB, 200,000 หน่วยรหัส UTF-16 และ 4,000 บรรทัด ไม่รองรับ PDF, เอกสาร Word, ไฟล์ไบนารี หรือทั้งโฟลเดอร์ เริ่มจากไฟล์โค้ดสองไฟล์ที่คุณรู้จัก ค้นหาความแตกต่าง แก้ไข ทดลอง Undo แล้วดาวน์โหลด B
