Compare Code compares and edits the files you choose on your device. This page explains what the application does with your information and what happens when you visit the website.

Code and files

The application reads a file only after you select it in a file picker. It also processes text you paste or type into the two editors. Comparison and syntax checking run locally, using the downloaded application and a local browser worker.

The application does not upload your code or selected filenames to a server or an AI service. It does not execute the code being compared, resolve its imports, read your other tabs, or access files you have not chosen.

Your session is kept in memory

Editor text, Undo/Redo history and review progress remain in the open tab's memory. The application does not save them to a cloud account, browser storage or a session database. Closing or reloading the page discards the active session; there is no automatic recovery.

Save session lets you explicitly download a JSON file containing both texts, filenames, selected language, view settings and remaining Keep B marks. The file preserves the UTF-8 BOM and line endings. It is not encrypted and does not include Undo/Redo history. Open session reads a file you choose locally and restores that workspace after confirmation when replacing existing work.

Use Clear both editors to discard both texts and their editing history. Downloaded files and clipboard contents are separate and are not removed by clearing the editors. Clearing or closing the tab is not a promise of secure erasure from browser or operating-system memory.

Downloads and clipboard

Download B creates a file from the result in B through your browser's download flow. It does not save A. Your browser controls the destination, whether the download completes and its usual download history. Check the downloaded file before leaving the page.

Copy B writes B to your system clipboard when you click the button. Your browser and operating system control the clipboard, including any clipboard synchronization you have enabled. Use Download B when you need to preserve the file's original line endings and UTF-8 BOM.

Website requests and hosting

Visiting the website sends normal HTTP requests to its hosting infrastructure to load the pages, scripts, styles and images. The infrastructure may receive or log connection information such as your IP address, requested URL, browser information and request time.

These website requests are separate from the code you enter into the editor. The comparison application includes no analytics, advertising, telemetry, external fonts, account system or tracking cookies. It does not add your code or selected filenames to website requests.

This describes the application itself. Your browser, browser extensions, hosting provider and any service you open through an external link may have their own data handling. The website needs a connection to load; offline reloading is not guaranteed.

Feedback and privacy questions

Feedback is voluntary and is not submitted automatically. Product and privacy questions can be raised through the project's GitHub issues. GitHub is a separate service, and its own privacy policy applies when you use it.

GitHub issues are public. Share a small, invented example when reporting a problem. Do not post private source code, credentials, personal data or screenshots containing sensitive information.
