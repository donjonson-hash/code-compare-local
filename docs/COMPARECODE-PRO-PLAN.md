## Что готово

| Область | Подтверждённое состояние |
| --- | --- |
| Визуальная концепция | Принят аниме-дизайн главной; прототип опубликован отдельно с закрытым доступом |
| Сравнение | Два редактируемых поля A/B, подсветка, список различий с номерами строк и Previous/Next |
| Правки | Выбранный A → B, All A → B, Keep B, Undo/Redo и прогресс просмотра |
| Надёжность переноса | Проверка ревизий и исходных фрагментов, защита от повторного и устаревшего применения |
| Повторяемость | Полный пересчёт различий по итоговым A/B, фиксированный бюджет поиска |
| Работа с длинными файлами | Only changes, отображение пробелов/табов, настройка размера кода |
| Файлы | Загрузка UTF-8, Copy B, Download B; сохранение BOM и LF/CRLF/CR, включая смешанные переносы |
| Синтаксис | JS/JSX/TS/TSX, JSON, YAML; предварительная проверка Python; отдельный локальный worker |
| Приватность расширения | MV3 без permissions/host_permissions, без сетевой обработки кода; CSP connect-src none |
| Инфраструктура | Исходники, lockfile, сборка, упаковка, unit и browser проверки установленного расширения |
| Материалы магазина | В main — комплект 0.8.0; в PR #8 — welcome, дополнительные иконки и 22 локализованных комплекта |

- Подключение comparecode.pro, DNS, HTTPS и редирект www. Состояние домена сегодня не проверялось.
- Перенос полезных изменений PR #8 на актуальную базу и согласование новой welcome page.
- Перевод интерфейса: локализованные карточки магазина не являются переводом редактора.
- Проверка нового сайта в Chromium и WebKit; проверки Chrome/Edge на macOS.
- Актуальный пакет для магазина, согласованный с новым брендом и интерфейсом.
- Факт публикации в Chrome Web Store: документация main сообщает, что бета не отправлена; кабинет магазина сегодня не проверялся.

Критерий готовности: проект воспроизводится из GitHub, главная открывает рабочий редактор,
принятый дизайн сохранён, функции main не потеряны.

## Этап 2 — общая сборка сайта и расширения

1. Использовать общее ядро сравнения, сохранения файлов и проверки синтаксиса.
2. Разделить оболочки: сайт с главной и автономное MV3-расширение.
3. Добавить воспроизводимые команды сборки веб-версии и установочного ZIP.
4. Обновить названия, иконки, ссылки, описания и версию согласованно.
5. Адаптировать сообщения ошибок worker для сайта: не предлагать установить расширение при веб-сбое.
6. Сохранить локальную обработку: сайт загружает приложение, пользовательский код не отправляется на сервер.

Критерий готовности: из одного коммита собираются оба продукта; расширение после установки работает offline.

## Этап 3 — проверить пользовательский сценарий

Основной сценарий для сайта и установленного расширения:
загрузить A/B → найти различие → перенести выбранный блок → Undo → Redo →
скачать B → открыть скачанный файл → проверить содержимое и байты.

Дополнительно:
- Ошибка синтаксиса появляется и исчезает после исправления; устаревшие результаты не отображаются.
- BOM, CRLF/LF/CR, Unicode, пустой файл и завершающий перенос не теряются.
- Двойное нажатие и устаревшая правка не затрагивают следующий блок.
- Only changes, Keep B, клавиатура, узкое окно и масштаб не скрывают основные кнопки.
- Проверить Copy B, загрузку и экспорт в Chromium и WebKit для сайта; Chrome/Edge для расширения.
- Проверить отмену скачивания: сейчас Download снимает dirty сразу после link.click(), что требует проверки предупреждения о несохранённых данных.
- Проверить сетевые запросы: пользовательский код не покидает браузер.
- Повторно использовать существующие содержательные тесты; добавлять регрессии только для новых рисков/найденных ошибок.

Критерий готовности: CI и основные сценарии проходят на точном коммите кандидата;
реальное скачивание подтверждено, а не только наличие кнопки.

## Границы первого выпуска

- Два UTF-8 файла: до 512 KiB, 200 000 единиц UTF-16 и 4 000 строк на сторону.
- Python — предварительная проверка, TypeScript — без проверки типов.
- Нет исполнения кода, проверки логики программы, сравнения проектов/папок/Git и трёхстороннего merge.
- Нет LLM/API-запросов; ручной выбор правок сохраняется.
- Сессия в памяти вкладки; восстановление после закрытия пока не входит в MVP.
- Расширение ориентировано на настольный Chromium; Safari-расширение и Firefox не входят в первый выпуск.
